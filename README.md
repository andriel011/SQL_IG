# InstagramDB

Base de datos inspirada en Instagram desarrollada en MySQL.

## Tablas

- Users
- Posts
- Likes
- Comments
- Follows
- Categories
- Account_Types

## Relaciones

- Un usuario crea muchos posts.
- Un usuario puede dar muchos likes.
- Un usuario puede seguir a muchos usuarios.
- Un post pertenece a una categoría.

## Archivos

- IG.sql -> Estructura de la BD.
- seed.sql -> Datos de prueba.
- view.sql -> Vistas.
- Query.sql -> Consultas de análisis.
