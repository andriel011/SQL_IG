# InstagramDB

## Project Description

InstagramDB is a relational database project developed in MySQL that simulates the core functionality of a social media platform similar to Instagram.

The database allows users to:

- Create accounts
- Publish posts
- Like posts
- Comment on posts
- Follow other users
- Categorize content

---

## Database Features

### Tables

1. Account_Types
2. Categories
3. Users
4. Posts
5. Likes
6. Comments
7. Follows

### Views

 vw_MainFeed
vw_UserFollowers

### Stored Procedures

GetPostsByUser

### Triggers

### Indexes

 idx_like_post
